# Audit of Missing Items & Architecture Standards

## Status Overview

| Item | Area | Description | Status | Verification & Resolution Details |
|:---:|:---|:---|:---:|:---|
| **1** | **F11 (Job Board)** | Frontend views (`JobsPage.tsx`, `HrJobsPage.tsx`) using real API hooks vs mock state | 🟢 **Resolved** | Both `JobsPage.tsx` and `HrJobsPage.tsx` use real modular hooks (`useJobSearch`, `useJobSuggestions`, `useHrJobPosts`, `useJobApply`) calling `/job/*` endpoints. Zero hardcoded in-memory state. |
| **2** | **F07 (Real-Time Chat)** | Frontend WebSocket client hooks and modular chat container | 🟢 **Resolved** | Modular `ChatContainer` in `fortlio-ui/src/features/chat/` and `useChatSocket.ts` connect to Bun WebSocket server on port 4021. |
| **3** | **MongoDB Aggregations First Standard** | Refactor services in `auth` and `candidate` from Mongoose `.populate()` / multi-query round-trips to MongoDB Aggregation Pipelines | 🟢 **Resolved** | Fully eliminated `.populate()` across `auth` and `candidate`. Added `getUserLoginAggregationPipeline` (collapsing 3 DB trips into 1), `getCandidateProfileByUserIdPipeline`, `getCandidateProfileByIdPipeline`, and `getUserWithRolePipeline`. |
| **4** | **Missing Marketed Sub-Features** | `POST /candidate/resume/ocr` (AI Resume OCR) & `POST /candidate/blog/improve-ai` (AI Blog Improver with Authentic Input Tracking) | 🟢 **Resolved** | Endpoints mounted in `candidate.route.ts`, validated in `candidate.validation.ts`, implemented in `candidate.service.ts` with `llmClient` & fallbacks, tested in `candidate.controller.test.ts`, and connected in UI via `ResumeOcrModal.tsx` and `BlogEditorForm.tsx`. |
| **5** | **Top Bar & Forti AI Opt-In Indicator** | Remove top bar global search bar and add Forti AI Button with glowing LED indicator and Credit Card Pro upgrade | 🟢 **Resolved** | Removed search bar from `Header.tsx`. Added pulsing green LED indicator reflecting `isAiOptedIn` status, PRO badge, and one-click modal (`FortiAiProModal.tsx`) supporting AI toggle, $29/mo Pro subscription via credit card, and coin packs. |
| **6** | **Specialty Blogs & Sidebar Navigation** | Remove Draw Your Imagination from sidebar navigation and make Specialty Blogs accessible to both Candidates and HRs | 🟢 **Resolved** | Removed standalone "Draw Imagination" from `Sidebar.tsx` navigation (preserved directly inside Markdown editors). Added "Specialty Blogs" to HR navigation section and mapped `/blogs` route alias in `App.tsx`. |
| **7** | **Universal Editor & A4 Sheet Pages** | Remove side padding in editors; render discrete A4 page cards with page breaks and page numbers (`Page X of Y`) in preview | 🟢 **Resolved** | Removed excessive horizontal padding (`py-3 px-1.5 md:px-2`) across `UnifiedMarkdownEditor.tsx`, `ResumeEditor.tsx`, and `BlogEditorForm.tsx`. Implemented discrete paginated A4 page preview cards with page numbering, visual break dividers, and bottom-right `By : [logo] Fortlio` watermark. |
| **8** | **Coin Purchases, Advertisements & LLM Token Tracking** | Credit card coin purchases, video ad rewards, and actual LLM token usage tracking per user/role | 🟢 **Resolved** | Added `tokensUsed`, `isPro`, and `isAiOptedIn` to user schema. Mounted `/user/purchase-coins`, `/user/upgrade-pro`, `/user/toggle-ai-optin`, and `/user/token-usage`. Candidate OCR and AI Blog Improver record token usage and deduct coins proportionally (1 coin per 100 tokens). |
| **9** | **Standardized User Communications (Web & SES)** | Enforce Web in-app notifications and AWS SES email notifications as the sole platform communication channels | 🟢 **Resolved** | Created unified `dispatchUserCommunication` in `communication.helper.ts` (persisting to MongoDB `Notification` collection and dispatching via AWS SES with graceful fallback). Integrated in user upgrade/coin services and candidate workflows. |
