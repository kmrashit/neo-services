# F04: Candidate Blogs, Knowledge Showcase, Draw Your Imagination & AI Blog Improver

## 1. Feature Overview
- **Feature ID**: F04
- **Module Name**: `candidate` (Blog Subsystem) / Frontend `blogs`
- **Backend Path**: `fortlio-be/src/modules/candidate/` (`candidate-blog.model.ts`)
- **Frontend Path**: `fortlio-ui/src/features/blogs/`
- **Status**: Completed (Backend ~95%, Frontend ~95%, Bun Tests 100%, Playwright E2E 100%, Overall ~98%)

F04 allows candidates across any profession or background to author and publish specialty learning blogs in Markdown. This showcases candidates' deep domain expertise, thought leadership, and intellectual depth to recruiters, boosts platform SEO, and powers candidate knowledge verification.

### Key Subsystems:
1. **Unified Editor (Medium-Like Article View)**:
   - Built on Fortlio's universal markdown editor engine configured in **Blog Mode**.
   - **Medium-Like Reading/Writing Layout**: Clean single-column editorial typography, reading time estimation, author attribution banner, tag clusters, and distraction-free preview.
2. **Draw Your Imagination (Visual Architecture & Concept Canvas)**:
   - Integrated directly into the unified editor, enabling candidates in engineering, medicine, law, finance, science, or design to illustrate domain concepts (system architecture, clinical pathways, process flows).
   - 1-click export and embedding into the markdown draft as `![Diagram](...)` or Mermaid blocks.
3. **Help Me Write Blog (with Authentic Candidate Input Tracking)**:
   - Candidates can request AI writing assistance (`POST /candidate/blog/improve-ai`) for structure, clarity, and domain polish.
   - **CRITICAL ARCHITECTURAL RULE**: **Forti AI evaluates the candidate strictly based on their authentic inputs, draft revisions, and original thoughts, NOT synthetic AI output.**
   - The editor captures the candidate's authentic draft history (`originalDraft`, revision diffs), ensuring Forti AI evaluates genuine learning velocity, conceptual depth, and leadership traits without rewarding superficial automated generations.

**Crucially, publishing or updating a blog post automatically triggers the Forti AI Engine (F09)** via BullMQ to calculate the candidate's learning velocity, knowledge depth in their discipline, topic diversity, and leadership mindset traits based on these authentic inputs.

## 3. Backend Architecture (`fortlio-be/src/modules/candidate/`)

### File Organization
```
fortlio-be/src/modules/candidate/
├── models/
│   └── candidate-blog.model.ts # Mongoose blog schema (title, slug, content, tags, views)
├── candidate.controller.ts     # createBlog, listBlogs handlers
├── candidate.service.ts        # Blog CRUD and query methods
├── candidate.validation.ts     # CandidateBlogCreateValidation
├── candidate.queries.ts        # Aggregation pipelines for blog feed & author lookup
└── candidate.route.ts          # /candidate/blog and /candidate/blogs routes
```

### Endpoints
- `POST /candidate/blog`: Auth-guarded (`createCandidateBlog`). Creates blog post with Markdown content, auto-generated slug, tags, and author reference. Automatically enqueues Forti AI insights synthesis job.
- `GET /candidate/blogs`: Public endpoint. Query parameters: `page`, `limit`, `tag`, `authorId`, `search`. Returns paginated list with total count.

### MongoDB Aggregation & Coding Rules
- Blog queries in `candidate.queries.ts` use an aggregation pipeline with:
  1. `$match` for active posts and optional tag/author filtering.
  2. `$lookup` joining `users` to project author name, avatar, and headline.
  3. `$facet` stage to compute pagination metadata (`total`, `page`, `pages`) and data results simultaneously in one database trip.

### Forti AI Asynchronous Hook
```typescript
// Dispatched in candidate.service.ts upon successful blog persistence:
await bullMQService.addJob(
  BULLMQQUEUES.FORTI_INSIGHTS_QUEUE,
  'synthesize-candidate-insights',
  { candidateId: blog.authorId, blogId: blog._id }
);
```
