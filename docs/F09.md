# F09: Forti AI Engine (Authentic Input Evaluation, Insights, Leadership & HR Chatbot)

## 1. Feature Overview
- **Feature ID**: F09
- **Module Name**: `forti`
- **Backend Path**: `fortlio-be/src/modules/forti/`
- **Frontend Path**: `fortlio-ui/src/features/forti/`
- **Status**: Completed (Backend 100%, Frontend 95%, Overall ~98%)

F09 is Fortlio's cross-cutting intelligence engine. Built as a decoupled, universally callable AI orchestration layer across all professions and academic backgrounds, Forti provides:
1. **Automated Candidate Insight Synthesis with Authentic Input Evaluation**:
   - When a candidate publishes or edits a specialty blog (F04), an asynchronous BullMQ worker triggers Forti AI.
   - **CRITICAL EVALUATION PRINCIPLE (Authentic Candidate Input Rule)**:
     - Even when candidates use AI tools (e.g. *Improve Your Blog with AI*), **Forti AI evaluates and judges the candidate strictly based on their authentic inputs, draft history, thesis, and original problem-solving thoughts**, rather than synthetic text.
     - The engine compares raw candidate drafts against polished text to extract the candidate's authentic reasoning, preventing over-reliance or gaming of scores via automated generation.
   - Forti evaluates:
     - **Learning Velocity & Trajectory**: How rapidly the candidate acquires new concepts in their specialty through authentic curiosity.
     - **Knowledge Depth & Volume**: Technical and domain maturity and conceptual depth in their field based on their original arguments.
     - **Domain & Interest Diversity**: Variety of topics and subdisciplines explored.
     - **Leadership & Soft Qualities**: Evaluates mentorship tendencies, critical thinking, strategic judgment, and collaborative mindset detected through their writing.
   - Synthesized insights are saved to MongoDB and indexed into Typesense so HRs can search candidates by AI-detected qualities, leadership tags, and niche tech domains.
2. **HR Profile AI Chatbot ("Chat with Candidate Profile")**:
   - HR recruiters can open an AI chat drawer on any candidate's profile to converse with an AI grounded in the candidate's complete portfolio (resume, experiences, education, blogs, and insights).
   - Enables recruiters to ask specific qualification and behavioral questions (e.g. *"What distributed systems experience does this candidate show in their blogs?"*, *"Summarize their learning trajectory over the last 6 months"*).

## 3. Backend Architecture (`fortlio-be/src/modules/forti/`)

### File Organization
```
fortlio-be/src/modules/forti/
├── forti.controller.ts          # SSE chat endpoint, get insights, manual trigger
├── forti.service.ts             # Orchestrates LLM prompt pipelines & portfolio RAG
├── forti.prompts.ts             # System prompts for insight synthesis & profile Q&A
├── forti.route.ts               # Express router (/forti/*)
├── forti.validation.ts          # Zod schemas for chat queries and insight payloads
├── forti.queries.ts             # Aggregation pipelines gathering candidate portfolio context
├── forti.constants.ts           # Status constants and prompt configurations
├── forti.registry.ts            # OpenAPI documentation registry
└── models/
    └── candidate-insight.model.ts # Schema: candidateId, learningVelocity, leadershipTags, topicDiversity
```

### Data Schema (`candidate_insights`)
```typescript
{
  candidateId: mongoose.Schema.Types.ObjectId; // References CandidateProfile
  learningVelocity: {
    score: number;             // 1 - 100 velocity score
    summary: string;            // Qualitative summary of recent learning pace
    progressionRate: 'rapid' | 'steady' | 'exploratory';
  };
  knowledgeVolume: {
    articleCount: number;
    depthLevel: 'introductory' | 'intermediate' | 'advanced' | 'expert';
  };
  topicDiversity: {
    primaryDomains: string[];   // e.g. ["Backend", "Cloud Architecture"]
    exploredTopics: string[];   // e.g. ["Kafka", "Kubernetes", "ClickHouse", "Rust"]
    diversityScore: number;     // 1 - 10 score
  };
  detectedQualities: {
    leadership: string[];       // e.g. ["Mentorship", "System Architecture", "Best Practices"]
    mindset: string[];          // e.g. ["Curious", "Production-Oriented", "Resilient"]
  };
  rawAiSummary: string;         // Comprehensive executive summary for recruiters
  lastSynthesizedBlogId: mongoose.Schema.Types.ObjectId;
  timestamps: true
}
```

### Endpoints
- `GET /forti/chat/candidate/:userId?question=...`: Server-Sent Events (SSE). Streams AI answers grounded in the candidate's portfolio.
- `GET /forti/insights/:candidateId`: Auth-guarded. Returns structured AI insights for candidate or HR.
- `POST /forti/insights/generate/:candidateId`: Internal / Admin trigger to force re-evaluation of candidate insights.

### Portfolio Grounding & Prompt Strategy
1. **Insight Synthesis Prompt (`forti.prompts.ts`)**:
   - Feeds candidate's existing work history, previously stored insights, and new blog posts.
   - Instructs LLM to output structured JSON adhering to `candidate_insights` schema.
   - Analyzes technical rigor, clarity of explanations, problem framing, and leadership cues.
2. **HR Profile Q&A Prompt**:
   - Injects full candidate context (profile, skills, experiences, blogs, and insights).
   - Restricts answers strictly to candidate's verified evidence to prevent hallucinations.
   - Streams formatted Markdown responses with source references (e.g., *"According to their blog on Cloud Architecture..."*).

### Cross-Module Universal Access
- Other modules trigger Forti without tight coupling:
  - When F04 (Blogs) creates a blog, it adds a job: `bullMQService.addJob(BULLMQQUEUES.FORTI_INSIGHTS_QUEUE, 'synthesize-insights', { candidateId, blogId })`.
  - HR Search (F05) queries `candidate_insights.detectedQualities` via MongoDB aggregation and Typesense keywords.
