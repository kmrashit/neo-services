# F03: Candidate Profile & Resume Generator (MD-to-PDF)

## 1. Feature Overview
- **Feature ID**: F03
- **Module Name**: `candidate`
- **Backend Path**: `fortlio-be/src/modules/candidate/`
- **Frontend Path**: `fortlio-ui/src/features/candidate/`
- **Status**: In Progress (Backend ~90%, Frontend ~45%, Overall ~67%)

F03 is the core portfolio showcase of Fortlio. Candidates construct comprehensive professional profiles (skills, experiences, education, portfolio links, bios), configure privacy masking (phone/email masked for unauthenticated or non-HR users), write markdown resumes, and export pixel-perfect PDF resumes using headless Puppeteer/Chromium.

## 3. Backend Architecture (`fortlio-be/src/modules/candidate/`)

### File Organization
```
fortlio-be/src/modules/candidate/
├── candidate.controller.ts    # Profile upsert, get with masking, MD-to-PDF
├── candidate.service.ts       # Profile persistence & retrieval
├── candidate.route.ts         # Express router (/candidate/*)
├── candidate.validation.ts    # Zod schemas for candidate profiles & MD-to-PDF
├── candidate.interface.ts     # TypeScript interfaces for candidate profile
├── candidate.queries.ts       # MongoDB aggregation pipelines for profile fetching
├── candidate.constants.ts     # Status and error messages
├── candidate.registry.ts      # OpenAPI specs
└── models/
    ├── candidate.model.ts     # Mongoose schema for candidate profiles
    └── candidates.collections.ts # Typesense collection schema for candidates
```

### Endpoints
- `POST /candidate/profile`: Upsert profile (bio, headline, skills array, experience, education, links).
- `GET /candidate/profile/:userId`: Retrieve candidate profile.
  - If requester is the candidate or an authorized HR: full contact details returned.
  - If requester is a guest or unauthorized: `maskEmail()` and `maskPhone()` are applied.
- `POST /candidate/md-to-pdf`: Convert markdown resume string with PDF styling options into binary PDF stream.

### MongoDB Aggregation & Coding Rules
- Use `getCandidateProfilePipeline` in `candidate.queries.ts` to join user data, role, candidate profile, and published blogs in one single aggregation stage.
- Privacy masking is applied in controller/service without extra round-trips.
