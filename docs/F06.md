# F06: Connections & Notification System

## 1. Feature Overview
- **Feature ID**: F06
- **Module Name**: `connection`
- **Backend Path**: `fortlio-be/src/modules/connection/`
- **Frontend Path**: `fortlio-ui/src/features/connections/`
- **Status**: In Progress (Backend ~85%, Frontend ~40%, Overall ~62%)

F06 governs professional networking across the platform. Candidates and HR recruiters can send connection requests, accept or reject pending invitations, list connections, and receive real-time notifications for incoming connection requests and status updates.

## 3. Backend Architecture (`fortlio-be/src/modules/connection/`)

### File Organization
```
fortlio-be/src/modules/connection/
├── connection.controller.ts    # Request, respond, list, notification handlers
├── connection.service.ts       # Connection business logic & DB transactions
├── connection.route.ts         # /connections/* router
├── connection.validation.ts    # Zod schemas for connection & response DTOs
├── connection.queries.ts       # MongoDB aggregation pipelines for user connections
├── connection.constants.ts     # Status codes and error messages
├── connection.registry.ts      # OpenAPI specs
└── models/
    ├── connection.model.ts     # Connection schema (requester, receiver, status)
    ├── notification.model.ts   # Notification schema (recipient, type, metadata, isRead)
    └── chat-message.model.ts   # Chat message schema (shared module storage)
```

### Endpoints
- `POST /connections/connect`: Auth-guarded (`createConnection`). Sends invite to `receiverId`. Automatically creates notification.
- `POST /connections/respond/:connectionId`: Auth-guarded (`respondToConnection`). Updates status to `'accepted'` or `'rejected'`.
- `GET /connections/list`: Auth-guarded (`listConnections`). Query: `status` (`'pending' | 'accepted' | 'all'`).
- `GET /connections/notifications`: Auth-guarded (`listNotifications`). Retrieves notifications for current user.
- `POST /connections/notifications/read/:notificationId`: Auth-guarded (`markNotificationAsRead`).

### MongoDB Aggregation & Coding Rules
- `connection.queries.ts` uses `$facet` and `$lookup` to join both `users` and `candidate_profiles` so the UI receives full counterpart names, avatars, and professional headlines in a single query.
- Uses atomic `$set` and `$addToSet` in MongoDB for status changes.
