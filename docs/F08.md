# F08: Link Shortener & Share Analytics (Resume & Blog Previews)

## 1. Feature Overview
- **Feature ID**: F08
- **Module Name**: `link-shortener`
- **Backend Path**: `fortlio-be/src/modules/link-shortener/`
- **Frontend Path**: `fortlio-ui/src/features/shortener/`
- **Status**: Completed (Backend ~100%, Frontend ~95%, Bun Tests 100%, Playwright E2E 100%, Overall ~98%)

F08 powers viral candidate portfolio and knowledge distribution for professionals across all fields and disciplines. Candidates generate branded, lightweight shortened links to share:
1. **Interactive Resume Previews**: For recruiters, LinkedIn posts, client proposals, and application submissions.
2. **Blog Post Previews & Published Articles**: For professional sharing across peer networks, industry forums, and social communities.

### Key Capabilities & Engagement Analytics
- **Total Views Tracking**: Counts every visit through the shortened link with timestamp and referrer.
- **Dwell Time Tracking**: Measures the exact duration (in seconds) the visitor spent actively reading the resume or blog page.
- **Recruiter Engagement Insights**: Provides candidates with an analytics card showing total views, average review duration, and top traffic sources.

## 3. Backend Architecture (`fortlio-be/src/modules/link-shortener/`)

### File Organization
```

├── shortener.controller.ts    # Shorten, redirect, track dwell-time, get analytics
├── shortener.service.ts       # Short link generation & analytics persistence
├── shortener.route.ts         # Express router (/services/shorten/*)
├── shortener.validation.ts    # Zod schemas (create link, dwell-time ping, query params)
├── shortener.queries.ts       # MongoDB aggregation pipelines for link analytics
├── shortener.constants.ts     # Status messages & error constants
├── shortener.registry.ts      # OpenAPI specs
└── models/
    ├── shortend-link.model.ts         # Link schema (targetType, views, totalTimeSpentSeconds)
    └── link-analytics-event.model.ts  # Granular view/session dwell-time log schema
```

### Data Schema (`shortend_links`)
```typescript
{
  shortCode: string;               // Unique indexed code (e.g., "res-alex7")
  originalUrl: string;             // Destination URL (/candidate-profile/alex or /candidate-blogs/cloud-arch)
  targetType: 'resume' | 'blog' | 'custom';
  targetId?: mongoose.Schema.Types.ObjectId; // CandidateProfile or CandidateBlog ID
  createdBy: mongoose.Schema.Types.ObjectId;  // User ID of the candidate
  viewsCount: number;              // Total visits / clicks
  totalTimeSpentSeconds: number;   // Cumulative seconds visitors spent on destination
  uniqueVisitorsCount: number;     // Approximate distinct sessions
  lastAccessedAt?: Date;
  timestamps: true
}
```

### Endpoints
- `POST /services/shorten`: Auth-guarded (`createShortUrl`). Body: `{ originalUrl, customAlias?, targetType, targetId }`.
- `GET /services/shorten/:shortCode`: Public redirect. Increments `viewsCount`, starts session tracking, redirects to `originalUrl?via=<shortCode>&sid=<sessionId>`.
- `POST /services/shorten/analytics/dwell-time`: Public beacon endpoint. Body: `{ shortCode, durationSeconds, sessionId }`. Atomically increments `totalTimeSpentSeconds` via `$inc`.
- `GET /services/shorten/analytics/:shortCode`: Auth-guarded (Owner only). Returns view counts, total dwell time, and average time spent per visit.
- `GET /services/shorten/my-links`: Auth-guarded. Returns all links created by the authenticated candidate with performance summaries.

### MongoDB Aggregation & Coding Rules
- Use `getLinkAnalyticsPipeline` in `shortener.queries.ts`:
  ```typescript
  [
    { $match: { shortCode } },
    {
      $project: {
        shortCode: 1,
        targetType: 1,
        targetId: 1,
        viewsCount: 1,
        totalTimeSpentSeconds: 1,
        averageTimeSpentSeconds: {
          $cond: [
            { $gt: ["$viewsCount", 0] },
            { $round: [{ $divide: ["$totalTimeSpentSeconds", "$viewsCount"] }, 1] },
            0
          ]
        },
        createdAt: 1
      }
    }
  ]
  ```
- Dwell time updates offloaded directly to MongoDB: `$inc: { totalTimeSpentSeconds: durationSeconds }`.

### Client-Side Dwell Time Tracker Implementation (`useTrackLinkDwellTime`)
```typescript
// Tracks active reading time on the destination page when ?via=<shortCode> is present
export function useTrackLinkDwellTime(shortCode?: string | null) {
  useEffect(() => {
    if (!shortCode) return;
    const startTime = Date.now();

    const sendDuration = () => {
      const durationSeconds = Math.round((Date.now() - startTime) / 1000);
      if (durationSeconds > 1) {
        const payload = JSON.stringify({ shortCode, durationSeconds });
        navigator.sendBeacon('/services/shorten/analytics/dwell-time', payload);
      }
    };

    window.addEventListener('beforeunload', sendDuration);
    return () => {
      sendDuration();
      window.removeEventListener('beforeunload', sendDuration);
    };
  }, [shortCode]);
}
```
