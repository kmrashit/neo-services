# Code Review Procedure

Use this skill to evaluate proposed code changes before committing or opening a pull request.

## Checklist
1. Review git status and git diff.
2. Verify absence of security flaws, SQL/NoSQL injection risks, or leaked credentials.
3. Verify test coverage and error handling.
4. Check style compliance with project rules.
