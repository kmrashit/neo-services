# Evaluation & Benchmark Procedure

Use this skill to systematically run evaluations on agent prompts, outputs, or dataset fixtures.

## Steps
1. Identify the prompt or feature to evaluate.
2. Run test cases against defined golden datasets or fixtures.
3. Collect metrics on accuracy, latency, and correctness.
4. Report comparison table.
