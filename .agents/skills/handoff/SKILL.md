# Session Handoff Summary

Use this skill when concluding a task or handing off to another agent session.

## Handoff Template
1. **Summary of Changes**: What was built, modified, or deleted.
2. **Current State**: Test results, build status, any active services.
3. **Pending / Next Steps**: Concrete actions remaining to complete the goal.
