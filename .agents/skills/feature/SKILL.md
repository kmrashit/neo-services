# Feature Implementation Workflow

Use this skill when developing a new feature.

## Steps
1. **Analyze Requirements**: Clarify inputs, outputs, error handling, and performance criteria.
2. **Design**: Check existing models and services to maintain architectural consistency.
3. **Implement**: Write code adhering to repository rules (e.g. MongoDB aggregations, TypeScript types).
4. **Test**: Author unit and integration tests covering edge cases.
5. **Verify**: Run tests and linting to ensure zero regressions.
